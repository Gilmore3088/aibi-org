Scenario Practice

Three reps every consumer lender should run.

Sandbox scenarios let lenders practice with synthetic files before AI touches a real application.

Active Sandbox Scenario
Auto Loan · Credit Memo Draft
Input
Synthetic auto-loan file: applicant earns $58k W-2, FICO 692, 38% DTI, requesting $24k for a used 2022 SUV with $26k NADA value.
Prompt
Draft a credit memo using the 5 Cs. Pull capacity, capital, collateral, conditions, and character from the file. Flag any data points that conflict. Recommend approve / counter / decline with reasoning the loan committee can defend.
Expected Output
Structured memo: strengths, weaknesses, mitigants, recommendation, and a "needs from applicant" list. No fabricated bureau detail.

Pre-send Checklist
Before any lending letter or memo goes out
Reason codes were picked by a lender, not the model
Specific principal reasons stated (Reg B §1002.9)
FCRA credit-score disclosure attached when bureau data used
No protected-class language in the prose
Numbers in the memo tie to a document in the file
Notice sent within 30 days of completed application
Audit log includes prompt version + reviewer initials
