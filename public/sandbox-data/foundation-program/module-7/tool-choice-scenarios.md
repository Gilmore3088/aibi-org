# Module 7: Tool Choice Scenarios

Decide whether each tool belongs in the workflow. Capability is not the same as approval.

## Scenario 1: Public Rate Sheet Summary

Task: Summarize a public rate sheet for a staff huddle.

Data class: Public.

Approval status: General AI drafting tool is approved for public information.

Concern: Staff must verify the current rate sheet before use.

## Scenario 2: Vendor Contract Review

Task: Ask a public AI tool to review a vendor contract with pricing and security terms.

Data class: Confidential.

Approval status: Public tool is not approved for confidential contracts.

Concern: Vendor terms and security details should not be pasted.

## Scenario 3: Customer Complaint Draft

Task: Draft a response using a real member complaint.

Data class: Restricted if complaint includes NPI.

Approval status: Approved customer communication system required.

Concern: Public tools cannot receive the complaint text.

## Scenario 4: Internal Procedure Rewrite

Task: Rewrite an approved procedure excerpt for clarity.

Data class: Internal.

Approval status: Approved internal AI workspace allowed for sanitized excerpts.

Concern: Human owner must confirm policy meaning did not change.

## Scenario 5: Loan Decision Support

Task: Recommend approval or denial based on borrower facts.

Data class: Restricted.

Approval status: Not approved for staff-level public AI use.

Concern: Credit decisioning requires controlled systems and governance.
