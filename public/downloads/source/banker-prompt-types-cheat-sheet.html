Banker Prompt Types Cheat Sheet

Choose the work first, then write the prompt. Each type needs an allowed source, output format, reviewer, and data boundary.

Basic prompt types

Start with the six common jobs.

Draft

Create first-pass language.

Use for emails, scripts, summaries, huddle notes, and internal updates. Human approves before use.

Summarize

Condense approved material.

Use for public guidance, procedures, meeting notes, or de-identified themes. Check facts against the source.

Rewrite

Adjust tone, clarity, or length.

Preserve meaning. Do not add requirements, soften compliance language, or change product terms.

Extract

Pull actions and open items.

Use for dates, risks, owners, evidence, missing facts, and review questions. Extraction is not verification.

Compare

Show differences and uncertainty.

Use for draft versus source, versions, vendor responses, or policy options. Do not ask for legal conclusions.

Checklist

Turn work into steps.

Use for handoff, QA, training, review, and launch readiness. Reviewer confirms steps match approved source.

Prompt rule

If the type asks AI to decide, approve, deny, file, send, publish, investigate, or retain final output, rewrite it. The prompt should ask for draft support and require human review.
