Before you paste

Use uppercase brackets instead of real specifics.

The safest prompting habit is to remove sensitive facts before the prompt. Use consistent placeholders so reviewers can see what was stripped and what must be verified before final use.

Sensitive itemUse placeholderNotes
Customer name[CUSTOMER]Use fictional names only in training scenarios.
Account number[ACCOUNT_NUMBER] or [ACCOUNT_LAST4]Never paste the real account number into a public AI tool.
Account type[ACCOUNT_TYPE]Example: checking, savings, CD, HELOC.
Balance[BALANCE]Avoid exact amounts unless in an approved environment.
Amount[AMOUNT] or [AMOUNT_RANGE]Ranges are safer than exact values for examples.
Transaction[TRANSACTION] or [TRANSACTION_PATTERN]Use pattern-level language where possible.
Date[DATE] or [DATE_RANGE]Use if timing matters but identity does not.
Dispute or complaint[DISPUTE_SUMMARY] or [COMPLAINT_SUMMARY]Remove identity, account, and event details unless the tool is approved.
Credit reasons[HUMAN_PROVIDED_REASONS]AI may clarify; it does not choose, infer, rank, approve, deny, or decide.
SAR / AML facts[SYNTHETIC_CASE_FACTS]No real SAR, alert, transaction, or investigation facts in public tools.
Employee or personnel facts[EMPLOYEE_SCENARIO]No medical, accommodation, performance, or protected-class details in public tools.
Vendor or security facts[VENDOR_SUMMARY] or [SECURITY_REQUIREMENT]Do not paste credentials, API keys, tokens, configurations, or production access details.

Default stop rule

If the prompt contains a real customer, real account, real transaction, real complaint, real SAR/AML detail, real credential, or examiner-sensitive fact, stop and classify higher before using AI.
