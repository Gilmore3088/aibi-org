Role-specific platform guide

Recommended setup by department

The platform that fits a department depends on what they do every day. Three priority features and one or two platforms per role — the rest is preference.

Department Priority features Recommended platform Example use case
Lending File Analysis · Deep Research · Custom Instructions ChatGPT Plus + Perplexity Upload a loan package to ChatGPT to flag missing docs; use Perplexity to research borrower industry and recent regulatory updates.
Compliance Long Context · Deep Research · File Analysis Claude Pro + NotebookLM Load full SR 11-7 and Reg B documents into NotebookLM; use Claude for adverse-action language review against approved templates.
Retail / Branch Voice Mode · Custom Instructions · Workspace Integration M365 Copilot (enterprise) or ChatGPT Plus Transcribe and summarize customer meetings; draft follow-up emails using approved templates and placeholders.
Marketing Custom Instructions · Image Generation · File Analysis ChatGPT Plus + Gemini Advanced Maintain brand voice in Custom Instructions; generate campaign mockups with DALL-E and Imagen; refine copy against compliance disclosures.
BSA / AML Approved enterprise environment only · Long Context · Custom Instructions Approved enterprise AI (no public tools) Draft SAR narratives from analyst notes; structure CDD baselines; never input customer-specific data into public AI.
IT / InfoSec Code & Data Analysis · Workspace Integration · Deep Research Claude Pro + M365 Copilot Vendor security questionnaire review; code review for internal scripts; CVE / threat research with cited sources.

The platform-agnostic discipline

Whichever tool you choose, the rules are the same: strip the specifics, ask clearly, fact-check outputs, escalate risky decisions. The platform changes the buttons. It does not change the responsibility.
