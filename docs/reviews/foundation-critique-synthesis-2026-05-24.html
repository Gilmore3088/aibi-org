What the course earns

Consensus — at least three of five personas independently called these out as keepers.

M0.2 · DATA DISCIPLINE
"Describe the situation, not the person."
CRO, Branch Mgr, CEO, IT, Ops — five-of-five — call this the course's keeper line. Pattern-recognisable, role-portable, exam-defensible.
M1.1 · MENTAL MODEL
Token-prediction · training cutoff · hallucination-as-property
CEO & Branch Mgr both flagged the framing as the thing they would repeat to a board or to a teller. Honest about the floor, not over-claimed.
M3.1 / M3.3 / M3.4
Four-part brief + five patterns + violation drill
The most-praised paid-equivalent free content. Ops Analyst, Branch Mgr, CRO, CEO all named at least one. The clearest case for letting M0–M3 stand alone.
M5.1 · AGENT-HONESTY
"Drafts are not deployments."
IT Director & CEO both flagged the honesty about where agents are not ready. Rare for AI marketing material to volunteer this.
AESTHETIC + SOURCING
Ledger design + named statistics + no marketing pablum
No "FFIEC-aware." No "supercharge." Sources are named and date-stamped. The aesthetic reads as authoritative to a CEO and exam-appropriate to a CRO.
SECURITY · TECHNICAL TRACK
M2.1 SSO tripwire · M3.4 MNPI / PII separation
IT Director called both "best-in-class" for banker-targeted training. The off-limits list extending into creds/logs/configs on the technical track variant holds.

The single biggest red flag

CODE · COPY MISMATCH

Marcus's code read found that src/app/api/sandbox/chat/route.ts:102,189 accepts a client-supplied systemPrompt string and passes it directly to Anthropic. Lesson copy in M2.3 and M4.2 describes the sandbox as injection-resistant with a paste-time PII gate. The /run and /ab endpoints meet that description; /chat does not — yet the lesson UI shows learners no signal which endpoint they are exercising.

This is the only finding in the fleet that requires a code + copy reconciliation before any wider deployment. Either harden /chat to match the other two paths, or rewrite the M2.3 / M4.2 copy to describe the actual guarantee per endpoint.

Recommended sequencing

Order by exam-risk × cost-to-fix. Item 1 is a blocker before any wider deployment; the rest can run in parallel.

  1. Reconcile sandbox copy ↔ code (F1, F18). Either harden /api/sandbox/chat to match /run and /ab, or rewrite M2.3 / M4.2 to describe the actual guarantee per endpoint. Blocker for any wider deployment.
  2. Add an SR 11-7 / TPRM thread into M3.4 / M4.* / M5.1 lesson bodies (F3, F8, F17). Cite the named documents with section-level plain-English restatements per the M1.1 pattern.
  3. Build the M5.4 tool-blast-radius matrix (F5). One card: tool · what it produces · where it runs · what IT needs to know · synthetic-data discipline. Add an IT-handoff line before the "shipped a prototype" close.
  4. Bridge the M4 → M5 cliff (F4, F9). Add a transitional lesson (or expand M5.1) that walks from saved Skill → PRD → tool-choice. Settle on one vocabulary across the M3.5–M5.5 span.
  5. Resolve the Workbench Pack ghost (F11). Either ship the missing M4 lesson that produces it, or strip the references from M5.1 / M5.5.
  6. Acknowledge institutional approval gates (F2). One callout per affected lesson: "your bank may have a policy on what leaves your environment, even when the source is public — check it first."
  7. Retime the <15 min promise (F7). Either split M3.2 / M3.5 / M5.3 into shorter lessons, or change the M0.1 promise to "≤25 min for the longest lessons."
  8. First-use glossary (F6). One-line aside the first time each banking acronym (SR 11-7, MNPI, OCC, Reg E, ECOA) and AI term (few-shot, chain-of-thought, PRD) appears. Persist across the session.
  9. Track-variant content gaps (F14, F15, F16). Add: leadership institutional-brief artifact in M5.5; back-office Excel/Copilot pattern in M4.*; customer_facing denial-letter + collections drills.
  10. "What can go wrong, by department" lesson (F19). Inserts before the gate; converts hesitant buyers.
  11. M0 onboarding still (F12). 30-second annotated screenshot before M1.1 — "here is where you type, here is the answer."
