## What this catches (and doesn't)

**Catches:**
- Missing alt text on `<img>`
- Broken heading order (H1 → H3 with no H2)
- Form fields without labels
- Buttons without accessible names
- ARIA misuse (role="button" on a div without keyboard handlers, etc.)
- Landmark coverage gaps

**Doesn't catch:**
- Color contrast (disabled — see config note)
- Keyboard-only navigation flow (needs interaction tests)
- Screen-reader reading order (needs manual review with VoiceOver/NVDA)
- Focus management on modal open/close
- Live region announcements during async updates
