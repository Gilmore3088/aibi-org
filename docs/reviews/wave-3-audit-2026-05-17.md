## §15 Analytics — 2 real gaps found

The analytics module (`src/lib/analytics/events.ts`) is well-built — 9
typed event wrappers, mirror server-side via `trackServer` from
`@vercel/analytics/server`. But call-site verification turned up gaps:

| Event | Wrapper exists | Call sites | Gap? |
|-------|---------------|------------|------|
| `assessment_start` | ✅ | 1 | OK |
| `assessment_complete` | ✅ | 1 | OK |
| `email_captured` | ✅ | 1 | OK |
| **`briefing_booked`** | ✅ | **0** | ❌ **No Calendly CTA fires this event** |
| `purchase_initiated` | ✅ | 2 | OK |
| `purchase_completed` | ✅ | 0 (server) | OK — server-side `trackServer` in webhook |
| `module_completed` | ✅ | 2 | OK |
| `exam_completed` | ✅ | 1 | OK |
| **`certificate_issued`** | ✅ | **0** | ❌ **Never fired at issuance point** |

### Gap 1 — `briefing_booked` never fires

5 Calendly CTAs in the codebase, none wired:
- `src/app/for-institutions/samples/efficiency-ratio-workbook/page.tsx`
- `src/app/for-institutions/advisory/page.tsx`
- `src/app/assessment/page.tsx`
- `src/app/results/[id]/page.tsx`
- `src/app/courses/foundation/program/_components/CompletionCTA.tsx`

**Recommended fix:** wrap the Calendly CTA in a helper that fires
`trackBriefingBooked({ source })` on click. One small component, 5
import updates. Defer to a Wave 4.

### Gap 2 — `certificate_issued` never fires

Wrapper exists, but the certificate-issuance code in
`src/lib/certificates/` doesn't call it. Add the event at the point a
new certificate row is written (capstone approval flow).
