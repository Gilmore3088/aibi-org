The single biggest finding

CRITICAL · In-Depth Assessment · $99 paid product

Two scoring engines that can disagree on the same record. getTierV2 (12–48 band, free-flow), getTierInDepth/composeScore (0–100 phase, Briefing), and scoreToTier (floor-anchored quarters) all coexist. The stored readiness_tier can disagree with the displayed Briefing phase for the same user. Code comments admit this; the product does not.

For a $99 instrument whose entire value is the score, this is the single largest quality bug across the audit. Fix before any further marketing investment in the In-Depth funnel.
