# `docs/_archive/` — Folder Rules

## Purpose

Stale reference docs and audits. Kept for history; **not authoritative
for current development.**

## What's in here

- Pre-Ledger UI audits (`audit-2026-04-27.md`, `ui-review-2026-04-27.md`,
  `ui-review-2026-04-29.md`) — superseded by the Ledger refresh
  (see `docs/brand-refresh-2026-05-09/`)
- `AiBI-P-Practitioner-Course-Overview.md` — uses retired AiBI-P naming;
  superseded by `Plans/aibi-launch-spec-v2.md` §1
- `email-content.ts.archived` — old TS module retired during the
  MailerLite migration
- `archive-README.md` — README from the previous `docs/archive/` folder

## When to move a doc here

- A review's findings are obsolete (e.g., pre-refresh) → move here
- A reference doc uses retired naming and a new one supersedes it
- A code file was retired but kept for archeology

## Do not delete

Same rule as `Plans/_archive/`: archived docs explain why the project
moved in the direction it did. Search before reverting a decision.
