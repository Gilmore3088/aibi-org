How to use this page

  1. In MailerLite, build each automation below as a disabled draft (Automations → Create).
  2. For each email step, add a Custom HTML block and paste the HTML from that step's box (use the Copy HTML button).
  3. Set the subject (shown on each step) and the trigger/delays/suppression from the spec box.
  4. Send a test to jlgilmore2@gmail.com and james.gilmore@csiweb.com.
  5. Leave everything OFF until both remaining blockers clear (MailerLite DKIM + physical address); then enable.
