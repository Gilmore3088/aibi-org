# Module 5: Project Brief Scenario

Turn these messy notes into a project brief AI can safely reuse after human review.

## Messy Workstream Notes

Project: "AI rollout for operations"

Loose notes:
- Operations wants help reducing time spent on monthly exception report narratives.
- Current process: analyst exports exception list, manager reviews notes, analyst drafts summary, manager rewrites.
- Sample data can be sanitized to status counts, aging buckets, and owner groups.
- Do not paste account numbers, member names, employee performance notes, or unresolved investigation details.
- Desired output: first-draft narrative for internal manager review.
- Possible success metric: reduce manager rewrite time from [VERIFY] to [VERIFY].
- Risks: model invents causes, misses aged exceptions, or writes like the report is final.
- Reviewer: Operations manager.
- Compliance partner should review the prompt before any repeat use.
- Out of scope: automated decisions, customer notices, staff performance conclusions, SAR or fraud narratives.

## Missing Details To Verify

- Approved source export fields
- Baseline time spent
- Review cadence
- Where final narrative is stored
- Whether an approved AI tool is required

## Brief Quality Bar

A good brief shows goal, audience, source, constraints, format, success metric, risk owner, and reviewer on one page.
