# Module 3: Prompt Card Scenarios

Use these recurring tasks to build reusable CORE prompt cards. Keep placeholders. Do not use real customer data.

## Scenario 1: Branch Huddle Summary

Task: Turn manager notes into a short huddle message.

Audience: Branch staff.

Input shape: Redacted bullet notes about service reminders, deadlines, and owner names.

Risk: Staff may paste member examples unless the prompt forbids them.

Review owner: Branch manager.

## Scenario 2: Monthly Variance Narrative

Task: Convert finance bullets into a plain-English variance narrative.

Audience: CFO and department heads.

Input shape: Sanitized percentage changes and approved commentary.

Risk: The model may invent causes if the prompt does not require source-only reasoning.

Review owner: Finance manager.

## Scenario 3: Procedure Refresh

Task: Rewrite an internal procedure step into clearer language.

Audience: Operations team.

Input shape: Approved procedure excerpt with no customer examples.

Risk: The model may change policy meaning while making prose smoother.

Review owner: Procedure owner.

## Scenario 4: Meeting Prep

Task: Create internal talking points from a public agenda.

Audience: Executive sponsor.

Input shape: Public agenda, approved notes, and decision needed.

Risk: Confidential strategy should not be pasted as context.

Review owner: Executive assistant or sponsor.

## Scenario 5: Training Quiz Draft

Task: Draft knowledge-check questions from approved training notes.

Audience: New staff.

Input shape: Approved training notes.

Risk: Incorrect answer keys can train the wrong behavior.

Review owner: Training lead.
