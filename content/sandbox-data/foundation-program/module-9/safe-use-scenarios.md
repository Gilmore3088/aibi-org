# Module 9: Safe AI Use Scenarios

Classify each use case as Green, Yellow, or Red. Then turn the pattern into a checklist.

## Scenario 1: Public FAQ Draft

Draft an internal summary from public website FAQs.

Suggested classification: Green if verified before use.

## Scenario 2: Member Complaint Response

Paste a member complaint with names, dates, and account details into a public AI tool to draft a reply.

Suggested classification: Red.

## Scenario 3: Procedure Summary

Summarize an approved internal procedure excerpt in an approved AI workspace.

Suggested classification: Yellow. Human owner verifies meaning.

## Scenario 4: Loan Denial Recommendation

Ask AI to recommend whether a borrower should be denied.

Suggested classification: Red.

## Scenario 5: Staff Huddle Note

Turn redacted manager bullets into a branch huddle note.

Suggested classification: Green if no customer data or confidential strategy is included.

## Scenario 6: Vendor Risk Notes

Summarize a confidential vendor security questionnaire in a public AI tool.

Suggested classification: Red.

## Scenario 7: Training Quiz

Draft quiz questions from approved training notes.

Suggested classification: Yellow. Answer key must be verified.

## Scenario 8: Board Packet Commentary

Draft commentary using non-public financial performance and strategic plans.

Suggested classification: Red unless handled in an approved controlled system with governance.
